# ifs25045-p6-pbo2026-springboot-cashflow

Aplikasi web **Cashflow (Catatan Keuangan)** berbasis **Spring Boot 4.1.2**, **Maven**, **Vaadin 25.3.4**, dan **JDBC (PostgreSQL)** dengan **Clean Architecture** serta **integrasi OpenAI-compatible API** untuk membuat transaksi dari catatan bebas.

| | |
| --- | --- |
| Folder / Artifact Maven | `ifs25045-p6-pbo2026-springboot-cashflow` |
| Package | `org.delcom.ifs25045springbootcashflow` |
| Database | `pbo2026_cashflow` |

> Ganti `ifs25045` dengan username Anda pada nama folder, `pom.xml`, `application.yaml`, `sonar-project.properties`, dan package Java bila belum sesuai.

## Prasyarat

- JDK 25 (sama dengan proyek referensi Todo List dan `Jenkinsfile`)
- PostgreSQL
- Maven Wrapper (`mvnw` / `mvnw.cmd`) - tidak perlu install Maven

## Konfigurasi `.env`

```powershell
Copy-Item .env.example .env
```

```env
APP_PORT=8080

DB_CONNECTION=pgsql
DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=pbo2026_cashflow
DB_USERNAME=postgres
DB_PASSWORD=postgres

ROOT_USERNAME=admin
ROOT_PASSWORD=admin

UPLOAD_DIR=uploads

OPENAI_ENDPOINT=https://delcom.org/api/v1
OPENAI_KEY=key
OPENAI_MODEL=nama-model
```

- Akun **ADMIN** di-seed otomatis dari `ROOT_USERNAME` / `ROOT_PASSWORD`.
- Upload (bukti transaksi & foto profil) disimpan di `UPLOAD_DIR` dan dilayani di `/uploads/**`.
- `DotEnv` hanya mengisi nilai yang belum ada di environment; di server, environment platform didahulukan.
- `OPENAI_*` wajib valid agar tombol **Generate AI** bekerja. Jangan commit `.env` (sudah di `.gitignore`).

## Menjalankan

1. Buat database:

   ```sql
   CREATE DATABASE pbo2026_cashflow;
   ```

2. Jalankan:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

   Buka <http://localhost:8080> (atau `APP_PORT`). Login admin: `ROOT_USERNAME` / `ROOT_PASSWORD`.
   Tabel `users` dan `transactions` dibuat otomatis (`SchemaInitializer`).

3. JAR production:

   ```powershell
   .\mvnw.cmd clean package -Pproduction
   java -jar target\ifs25045-p6-pbo2026-springboot-cashflow-0.0.1-SNAPSHOT.jar
   ```

## Fitur

| Fitur | Keterangan |
| --- | --- |
| Auth | Register, login, logout; sesi bertahan setelah refresh (`AuthSession`: cookie `cashflow_uid` + flag logout) |
| Transaksi | Tambah Pemasukan / Pengeluaran, ubah (klik ganda baris), hapus dengan konfirmasi |
| Bukti | Upload gambar opsional (`proofPath`), klik thumbnail untuk zoom (`ImagePreviewDialog`) |
| Cari/filter/urut | Cari keterangan, filter tipe, 6 urutan (default **Terbaru**) |
| Saldo | Kartu total transaksi, pemasukan, pengeluaran, saldo (`Rp 1,000,000.00`) |
| Generate AI | Prompt catatan -> pratinjau transaksi -> simpan; `ProgressBar` saat memproses (async) |
| Profil | Nama, password, foto |
| ADMIN | Daftar pengguna + lihat transaksi user lain (read-only); admin punya cashflow sendiri |

### Rute

| Path | Akses |
| --- | --- |
| `/login`, `/register` | Publik (sudah login -> `/`) |
| `/uploads/**`, `/icons/**`, `styles.css` | Publik (static) |
| `/`, `/profile` | USER & ADMIN (belum login -> `/login`) |
| `/users`, `/user-transactions/{id}` | ADMIN saja (USER -> `/`) |

## Arsitektur

```text
src/main/java/org/delcom/ifs25045springbootcashflow/
├── domain/      # entity, exception, port (IRepository<T,ID>, ITransactionRepository, IUserRepository, IFinanceAiService), PasswordHasher
├── usecase/     # AuthUseCase, FinanceUseCase, FinanceAiUseCase, UserUseCase (tanpa Vaadin)
├── adapter/     # ai (OpenAiFinanceService, InMemoryFinanceAiService), presenter (FinancePresenter),
│                # repository (InMemory*, Jdbc*, SchemaInitializer), storage (FileStorage)
├── framework/   # auth (AuthSession), view (Vaadin)
├── config/      # AppConfig (composition root @Bean)
├── DotEnv.java
└── App.java
```

Dependency Rule: `domain <- usecase <- adapter / framework`. Runtime memakai JDBC + PostgreSQL; unit test memakai InMemory dan H2.

Skema transaksi:

```sql
CREATE TABLE IF NOT EXISTS transactions (
    id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id INTEGER NOT NULL,
    description TEXT NOT NULL,
    amount BIGINT NOT NULL,
    type VARCHAR(20) NOT NULL,
    proof_path VARCHAR(500),
    created_at TIMESTAMP NOT NULL,
    CONSTRAINT fk_transactions_user FOREIGN KEY (user_id) REFERENCES users(id)
);
```

## Integrasi AI

`FinanceView` -> `FinanceAiUseCase` -> `IFinanceAiService` -> `OpenAiFinanceService` (HTTP `POST {OPENAI_ENDPOINT}/chat/completions`).
AI diminta mengembalikan JSON array `{description, amount, type}` dengan `type` = `INCOME` / `EXPENSE`. Item tidak valid dilewati; hasil dipratinjau dulu sebelum disimpan. Pemanggilan berjalan async (`CompletableFuture` + `UI.access`).
Test AI memakai `InMemoryFinanceAiService` dan server HTTP lokal/mock, **tidak** memanggil API nyata.

## Troubleshooting

- `Gagal menginisialisasi schema database` / `Connection refused`: periksa `DB_*`, pastikan PostgreSQL hidup dan database `pbo2026_cashflow` sudah dibuat.
- Menjalankan JAR tanpa `-Pproduction` biasanya gagal (`vaadin-dev-server not found`).
- Generate AI gagal: periksa `OPENAI_ENDPOINT`, `OPENAI_KEY`, `OPENAI_MODEL`.
